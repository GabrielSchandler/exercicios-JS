## 🇧🇷 Português

### Sobre o projeto

Página com os exercícios que fiz durante o curso de JavaScript. Cada um treina um conceito diferente: manipulação do DOM, condicionais, laços de repetição e vetores.

| # | Exercício | O que faz |
|---|---|---|
| 1 | Hora do dia | Lê o horário do sistema e troca a foto e a cor de fundo (manhã, tarde ou noite). |
| 2 | Verificador de idade | Calcula a idade pelo ano de nascimento e mostra uma imagem de acordo com o sexo e a faixa etária. |
| 3 | Contagem | Conta do início ao fim com o passo informado pelo usuário. |
| 4 | Tabuada | Mostra a tabuada de 0 a 10 do número informado. |
| 5 | Analisador de números | Guarda números (de 1 a 100) em um vetor e mostra o total, o maior, o menor, a soma e a média. |

### Tecnologias

- HTML5
- CSS3
- JavaScript puro (DOM, condicionais, laços e arrays)

### Como usar

Baixe o repositório e abra o `index.html` no navegador.

### Estrutura

```
index.html    página com os 5 exercícios
estilo.css    estilos
script.js     lógica de cada exercício
images/       fotos usadas nos exercícios 1 e 2
```

## 🇺🇸 English

### About

A page with the exercises I did during a JavaScript course. Each one practices a different concept: DOM manipulation, conditionals, loops and arrays.

| # | Exercise | What it does |
|---|---|---|
| 1 | Time of day | Reads the system clock and changes the photo and background color (morning, afternoon or night). |
| 2 | Age checker | Calculates age from the birth year and shows an image matching sex and age group. |
| 3 | Counter | Counts from a start to an end value using a user-defined step. |
| 4 | Multiplication table | Shows the 0–10 multiplication table for a given number. |
| 5 | Number analyzer | Stores numbers (1–100) in an array and shows the count, max, min, sum and average. |

### Tech stack

- HTML5
- CSS3
- Vanilla JavaScript (DOM, conditionals, loops and arrays)

### Usage

Download the repository and open `index.html` in your browser.
